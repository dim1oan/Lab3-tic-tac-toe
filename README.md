# Лабораторная работа №3: «Крестики-нолики» (Tkinter)

Графическое приложение для игры «Крестики-нолики» для двух игроков, разработанное на Python с использованием стандартной библиотеки `tkinter`.

## Возможности приложения
- Пошаговая игра для двух игроков (`X` и `O`) на поле 3×3 с подсчетом счета.
- Верхнее меню: **«Игра»** («Новая игра», «Выход») и **«Справка»** («Об авторе»).
- Поддержка свободного изменения размеров окна с пропорциональным масштабированием поля и символов.
- Обработка исключений (`CellOccupiedError`, `GameFinishedError`, `InvalidCellError`, `tk.TclError`) с информативными окнами `messagebox`.

## Запуск
```bash
python main.py
```
